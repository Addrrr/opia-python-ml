# Predicción del precio de casas en California (servicio web)

Autores: Mariano Clavero y Adrián Tortosa

## Contenido del repositorio

El repositorio contiene .gitignore, README.md, este mismo documento (README2.md) y una 
carpeta llamada src. La carpeta contiene otro README.md, un app.py, arbol_decision.png,
medir_tiempos.py, model_training.py, modelo_california.pkl, modelo_california.py, y
requirements.txt

## Pasos del despliegue

Primero nos registramos en render con la cuenta de github donde esta el repositorio, luego
creamos un nuevo servicio de red (Web Service) especificando el repositorio concreto, despues
configuramos el render para que sea capaz de funcionar, para finalizar configuramos el 
requirements.txt para que render pueda configurar las librerias de los archivos .py y ya 
empezo a funcionar.
